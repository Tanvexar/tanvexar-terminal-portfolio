# ⚡ Tanvexar Terminal Portfolio

> Interactive terminal-style portfolio with real-time system simulation, recon UI, and cyberpunk-inspired animations.

---

## 🧠 Overview

This project is a **fake OS / terminal-based portfolio interface** that simulates a hacking environment inside the browser.

It allows users to interact through terminal commands, view system data, and experience cyberpunk-style UI animations.

---

## 🚀 Features

- 💻 Terminal command system
- ⚡ Boot sequence animation
- 🔍 System reconnaissance dashboard
- 🌐 Live IP, OS, browser detection
- 🧬 Matrix background animation
- 🐍 Snake game inside terminal
- 📂 GitHub API project loader
- 📨 Secure contact form (validation + anti-injection)
- 🔐 XSS / SQL injection filtering (frontend level)
- 🎭 Shatter-style animated button UI
- ⌨️ Typing + glitch effects

---

## 🛡️ Security Features

- Input validation for all fields
- Blocked keyword detection (SQLi / XSS patterns)
- Email filtering system (restricted domains)
- Basic spam protection logic
- Frontend-only security simulation (not backend hardened)

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (animations + pseudo effects)
- Vanilla JavaScript
- GitHub REST API
- Browser APIs (Battery, Network, Device info)
